# AI Finance Lab

Applied AI systems for financial research, built by a final-year Finance and
Financial Mathematics student.

This site is both the engineering documentation for the lab and the public,
dated archive of its daily output.

## Systems

| System | What it does | Status |
|---|---|---|
| Macro Research Digest | Automated daily pre-market macro note | in progress |
| Filings Intelligence | SEC/ASX retrieval with citations | planned |
| Deal & Comps Platform | Australian precedent transaction database | planned |
| Research Agent | Tool-calling agent orchestrating the above | planned |

See [Architecture](architecture/overview.md) for how the systems are built,
and [Decisions](adr/index.md) for why.
